## 三、结论

- 会员开通、积分扣费、配额计数、超限拦截、降级复核全链路**在真实 MySQL 上端到端跑通**。
- 支付回调具备**幂等性**，重复回调不会二次扣费。
- 配额超限触发 `QUOTA_EXCEEDED`，且计数**不会越界**；降级后配额上限**即时反映**。
