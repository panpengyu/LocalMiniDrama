#### 增加 3 个全局守卫变量（[ScreenwriterStudio.vue](file:///Users/panpengyu/Desktop/AI项目/LocalMiniDrama_web/front-user/src/views/ScreenwriterStudio.vue#L373-L382)）

#### 幕卡拖拽 5 个边界防护
1. **dragstart 预检**：若当前有任何幕 busy，弹出 warning 并 `preventDefault` 取消拖拽
2. **全局禁选**：拖拽开始 → `document.body.classList.add('screenwriter-drag-active')` → 应用 unscoped 全局 CSS（`user-select:none !important` + `input/textarea/select {pointer-events:none}`），从交互层彻底阻止选中
3. **drop 原子化**：`from/to` 两个 idx 先加进 busySet → `try/finally` 无论成功失败都清 busy、清拖拽标记、移除 body class（**避免拖拽取消/异常导致状态残留**）
4. **drop 无效分支兜底**：若 `from/to 相同 / 非拖拽活跃态`，直接走 `onActDragEnd()` 清状态
5. **onActDragEnd 双重兜底**：用户拖到窗口外/ESC/浏览器原生取消时，保证立即清除状态

#### 异步请求 3 个边界防护（onRegenerateAct / onSaveCharacter / onRegenerateCharacter）
1. **进入立即拦截**：isDraggingActive → return；已经在 busySet → return（ElMessage 提示）
2. **先占位后请求**：进入函数先 add(key) → 然后 await 请求 → **finally 里 delete(key)**，哪怕用户 100ms 连点 10 次，后续 9 次均命中 busySet 直接 return，不会触发并发请求

## 📝 任务 3：分隔条尺寸边界 & 状态持久化 —— 加固说明

针对 [DramaWorkbench.vue](file:///Users/panpengyu/Desktop/AI项目/LocalMiniDrama_web/front-user/src/views/workbench/DramaWorkbench.vue#L329-L632) 中的布局逻辑，我做了以下 7 个关键加固（解决极端窗口下布局错乱）：

### 🔧 1. 边界阈值更合理（适配 13" MacBook 小屏）

```javascript
const LAYOUT_BOUNDS = {
  left:     { min: 180, max: 420 },
  right:    { min: 260, max: 520 },   // AI面板控件最小容纳
  timeline: { min: 120, max: 420 },   // ← 从 140 降到 120（矮屏仍能显示卡片）
  center:   { minW: 320, minH: 200 }, // ← 从 420/260 降到 320/200（小屏不被强制挤爆）
}
```

### 🔧 2. `_enforceViewportConstraint()` 三段式压缩策略（水平方向）

```
窗口宽度 W：
  ① 先压右栏 → 若压到 min=260 还放不下 → 强制折叠 AI（rightPx=0）
  ② 再压左栏 → 保证 center ≥ 320（画布必须能看到）
  ③ 最终兜底：若仍溢出 → 左栏降到 140（极限保护）
```

这样 **W=800px**（1/2 屏）时：左 200 + 画布 320 + 右 260 + 间距 = 刚好 800 ；**W=600px** 时 AI 自动折叠，左 180 + 画布 320 = 500，留 100 给浏览器边框。

### 🔧 3. 折叠 / 展开状态宽度正确恢复

- `aiPanelCollapsed = true` → `rightColWidth = 0px`（**不会再**带着 360 宽度挤压画布）
- `aiPanelCollapsed = true → false` → 用 `_lastExpandedRightPx` 恢复上次展开时的宽度并重新 clamp
- 极端窄屏下点「展开」→ 立刻被折回 + `ElMessage.warning('当前窗口过窄…请拉宽')` + warn 日志

### 🔧 4. localStorage 版本兼容 + 崩溃兜底

```javascript
// 版本号校验：若未来升级到 LAYOUT_LS_VER=2 → 旧 v1 布局自动丢弃用默认
if (!parsed || typeof parsed.v !== 'number' || parsed.v < LAYOUT_LS_VER) {
  log.warn('[Layout] localStorage 布局版本过旧，丢弃并使用默认值')
  return null

```

+ 隐私模式（Safari 无痕）下写入失败 → `warn` 日志 + 静默失败（**不再**抛异常白屏）。

### 🔧 6. 折叠状态下 **禁止拖动右栏分隔条**
