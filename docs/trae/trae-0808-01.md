### 3.2 公共代码共享策略

采用 **npm workspaces**，不走 symlink 复制代码，运行时共享：

1. 根 `package.json` 配置：
   ```json
   { "workspaces": ["packages/*", "front-user", "front-admin"] }
   ```

2. `packages/shared` 导出：`request` 工厂函数（接收 `{ baseURL, tokenKey }` 配置，两应用各自初始化）、通用 types/constants/styles。
3. token 完全隔离：
   - 用户端 `localStorage key = "user_token"` + `"user_info"`
   - 管理端 `localStorage key = "admin_token"` + `"admin_info"`

### 三、Y 轴自动缩写审查 + 强化（万 / 亿 / 万亿 + 负值 + Tooltip 双显示） ✅

原来的实现有两个关键缺陷：

新实现抽成统一工具（[format.js](file:///Users/panpengyu/Desktop/AI项目/LocalMiniDrama_web/front-admin/src/utils/format.js)）：

```js
export function fmtBigNumber(raw, opts = {}) {
  const n = Number(raw);
  if (!isFinite(n)) return '0';
  const sign = n < 0 ? '-' : '';
  const abs = Math.abs(n);
  if (abs < 10000) return sign + fmtInt(abs);           // < 1万: 千分位整数
  if (abs < 1e8)   return sign + (abs/1e4).toFixed(1) + '万'; // 1万~1亿: X.X 万
  if (abs < 1e12)  return sign + (abs/1e8).toFixed(2) + '亿'; // 1亿~1万亿: X.XX 亿
  return sign + (abs/1e12).toFixed(2) + '万亿';              // ≥ 1万亿: X.XX 万亿
}
```

| `48739` → `4.9万` | ✅ | 万级，1 位小数 |

## 二、2D/3D 数据双向同步逻辑

**核心问题**：2D变更触发3D更新，3D更新又触发2D更新，形成无限循环。

**解决方案**：脏标记 + 防抖 + 同步锁

```
2D节点位置变更
  → 标记 dirty2D = true
  → 防抖 50ms
  → 批量更新3D（syncing = true，阻止3D回环）
  → 清除 dirty2D

3D节点拖拽
  → 检查 dirty2D（如果2D正在同步，忽略此3D变更）
  → 标记 dirty3D = true
  → 防抖 50ms
  → 批量更新2D（syncing = true，阻止2D回环）
  → 清除 dirty3D
```

**关键设计点**：
- `syncing` 标志位：同步过程中忽略所有变更事件
- `dirty2D` 检查：3D变更时如果2D正在同步，直接丢弃（因为是回环触发）
- 50ms防抖：连续拖拽时批量处理，避免逐帧同步
- Z轴隔离：2D变更只影响X/Y，Z深度独立管理

## 三、LOD 降级策略实现

**4级降级体系**：

| 级别 | 距离阈值 | 渲染内容 | GPU开销 |
|------|---------|---------|---------|
| HIGH (0) | < 80 | 全纹理 + 文字标签 + 边框 | 高 |
| MEDIUM (1) | 80-200 | 低分辨率纹理(mipmap) + 无文字 | 中 |
| LOW (2) | 200-400 | 纯色平面(类型标识色) | 低 |
| HIDDEN (3) | > 400 或视锥体外 | 不渲染 | 零 |

**性能优化措施**：
1. **100ms节流**：LOD评估每100ms执行一次，非每帧
2. **平方距离**：用 `distanceToSquared` 替代 `distanceTo`（避免开方）
3. **视锥体剔除**：`Frustum.containsPoint` 快速剔除不可见节点
4. **级别缓存**：LOD级别未变化时跳过材质切换（`currentLOD === level`）
5. **Mipmap降采样**：中等LOD利用GPU自动选择mipmap级别，无需手动生成低分辨率纹理
6. **动态阈值**：`setDistanceThresholds()` 根据场景规模调整距离阈值
