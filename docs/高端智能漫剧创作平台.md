# 高端智能漫剧创作平台 — 改进规划

> **文档定位**: 基于当前 LocalMiniDrama 项目现状，对照业界高端漫剧创作平台标准，系统梳理改进方向与落地路径
> **目标愿景**: 打造一站式、智能化、高质量的漫剧创作平台，让创作者从"手动拼装"升级为"AI辅助编排"
> **创建日期**: 2026-08-08

> **免责声明**: 本文档中提及的第三方产品名称、服务名称及竞品名称仅用于技术选型参考和能力对比，相关商标和知识产权归各自所有者所有。竞品对标表中的评分基于公开信息的主观评估，仅供参考。技术选型建议中列出的产品均为示例，实际选型应根据项目需求、成本预算和合规要求独立评估。

## 一、当前项目现状评估

### 1.1 已具备的能力

| 维度 | 现有能力 | 成熟度 |
|------|---------|--------|
| **架构** | BS架构，前后端分离，npm workspaces 共享包 | ★★★★☆ |
| **创作核心** | 节点式画布编辑器（角色/道具/场景/分镜/脚本节点） | ★★★☆☆ |
| **AI生成** | 文生图、图生图、视频生成、音频提取、提示词优化 | ★★★☆☆ |
| **角色系统** | 角色库、四视图生成、SD2认证、面部锚点提取、语音上传 | ★★★☆☆ |
| **分镜系统** | 分镜CRUD、帧提示词、通用段落模式、尾帧链接、音频拆分 | ★★★☆☆ |
| **素材管理** | 媒体库、角色/场景/道具库、资产导入导出 | ★★★☆☆ |
| **管理后台** | 运营概览、用户/企业/团队管理、模型网关、财务系统 | ★★★★☆ |
| **数据安全** | 数据异常检测、告警通知、事务一致性保障 | ★★★★☆ |
| **SaaS能力** | 多企业/团队隔离、用户级AI配置、积分计费 | ★★★☆☆ |

### 1.2 核心差距

与业界高端漫剧创作平台（如 Animeta、Pika、Runway 等）相比，当前主要差距集中在：

1. **AI智能化深度不足** — 生成能力强但编排能力弱，缺乏端到端智能创作链路
2. **角色一致性技术薄弱** — 跨分镜角色面部/服装/风格一致性无法保证
3. **视频后期能力缺失** — 无智能剪辑、转场、配音同步、字幕生成
4. **协作能力为零** — 单人创作模式，无团队协作和版本管理
5. **用户体验分散** — 功能丰富但流程割裂，缺乏一站式创作引导
6. **素材复用效率低** — 无智能标签和推荐，跨项目复用困难

## 三、智能引擎层改进（核心优先级）

### 3.1 AI编剧助手

**现状**: 仅有基础的剧情拆分（PlotSplit）和故事生成（StoryGeneration），缺乏交互式编剧能力。

**改进目标**: 让创作者输入一句话创意，AI自动生成完整剧本大纲、角色设定、分集剧情。

**具体方案**:

```
创作者输入: "一个普通快递员意外获得超能力的故事"
         ↓
    ┌────────────────────────────────────┐
    │          AI 编剧引擎               │
    │                                    │
    │  1. 故事大纲生成（三幕式结构）       │
    │  2. 角色档案自动创建（主角/反派/配角）│
    │  3. 分集剧情拆分（每集3-5分钟）     │
    │  4. 分镜脚本自动生成（含镜头语言）   │
    │  5. 对话台词生成（角色语音匹配）     │
    │  6. 场景描述生成（含美术风格建议）   │
    └────────────────────────────────────┘
         ↓
    完整创作项目一键创建
```

**技术要点**:
- 基于现有 `storyGenerationService` 扩展，增加多轮对话式编剧能力
- 引入结构化剧本模板（三幕式、英雄之旅、起承转合等）
- 支持创作者对AI生成内容的逐段修改和重新生成
- 剧本与角色/场景/分镜数据自动关联，修改剧本时联动更新

**优先级**: P0 — 这是高端平台的核心差异化能力

### 3.2 角色一致性技术

**现状**: 有SD2认证和四视图生成，但跨分镜生成时角色面部、服装、风格容易漂移。

**改进目标**: 确保同一角色在所有分镜中保持面部、发型、服装、体型高度一致。

**具体方案**:

| 技术手段 | 说明 | 实现路径 |
|---------|------|---------|
| **参考图锚定** | 每次生成分镜图片时自动注入角色参考图 | 扩展 `imageService`，生成时自动附带角色正面/侧面参考图 |
| **LoRA训练集成** | 为重要角色训练专属LoRA模型 | 后端增加LoRA训练任务队列，前端角色详情页增加"训练模型"入口 |
| **IP-Adapter适配** | 使用IP-Adapter保持面部一致性 | 集成到图片生成流程，自动注入角色面部参考 |
| **角色指纹系统** | 为每个角色生成唯一身份指纹 | 基于现有 `character_identity_anchors` 扩展，存储面部embedding |
| **一致性校验** | 生成后自动比对角色一致性 | 调用视觉模型比对生成图与参考图，低于阈值自动重试 |

**优先级**: P0 — 角色一致性是漫剧质量的生命线

### 3.3 智能分镜系统

**现状**: 有分镜CRUD和帧提示词，但需要创作者手动编写每个分镜的描述。

**改进目标**: AI根据剧本自动生成专业分镜，含镜头语言、构图建议、情绪标注。

**具体方案**:

```
剧本段落 → AI分镜引擎 → 专业分镜列表
                         ├── 镜头类型（特写/中景/全景/远景）
                         ├── 运镜方式（推/拉/摇/移/跟）
                         ├── 构图建议（三分法/对称/引导线）
                         ├── 情绪标注（紧张/温馨/震撼/悲伤）
                         ├── 时长建议（2-5秒/5-10秒）
                         └── 转场建议（硬切/淡入淡出/叠化）
```

**技术要点**:
- 扩展 `episodeStoryboardService`，增加AI自动分镜能力
- 引入影视分镜专业知识库（镜头语言、蒙太奇理论）
- 支持创作者调整分镜参数后重新生成对应图片
- 分镜与角色/场景自动关联，生成图片时自动注入参考

**优先级**: P1

### 3.4 智能配音与音频

**现状**: 仅有音频提取和语音上传，无TTS自动配音能力。

**改进目标**: 根据角色设定和台词自动生成匹配的配音，支持多语言。

**具体方案**:

| 功能 | 说明 |
|------|------|
| **角色音色定制** | 每个角色绑定独特音色（年龄/性别/性格匹配） |
| **台词自动配音** | 从分镜脚本提取台词，自动调用TTS生成配音 |
| **情感语调控制** | 根据剧情情绪标注调整语速/语调/停顿 |
| **背景音乐生成** | AI根据场景氛围自动生成BGM |
| **音效智能匹配** | 根据分镜内容自动推荐环境音效 |
| **多语言配音** | 支持中/英/日/韩多语言一键配音 |

**技术要点**:
- 后端已有 `ttsService.js` 基础，需扩展为完整的配音流水线
- 集成主流TTS厂商（火山引擎、Azure、ElevenLabs等）
- 音频与分镜时间轴自动对齐
- 支持配音试听和逐句调整

**优先级**: P1

### 3.5 风格统一引擎

**现状**: 有风格预设（styleOptions.js）和风格缩略图，但跨分镜风格一致性靠手动维护。

**改进目标**: 全局风格锁定 + 分镜级别微调，确保整部漫剧视觉风格统一。

**具体方案**:

```yaml
# 项目级风格配置
style_config:
  global_style: "anime"           # 全局风格锁定
  color_palette: ["#FF6B6B", ...] # 主题色板
  line_weight: "medium"           # 线条粗细
  shading_style: "cel-shading"    # 渲染风格
  composition_rule: "rule-of-thirds"
  
  # 角色风格覆盖
  character_overrides:
    - id: "char_001"
      style: "realistic"  # 特定角色使用写实风格
  
  # 场景风格覆盖
  scene_overrides:
    - id: "scene_dream"
      style: "watercolor" # 梦境场景使用水彩风格
```

**优先级**: P2

## 四、创作工作流改进

### 4.1 一站式创作流程

**现状**: 创作流程分散在多个页面（FilmList → DramaDetail → FilmCreate → DramaCanvas），用户需要在页面间频繁跳转。

**改进目标**: 统一创作工作台，从创意到成片在一个界面内完成。

**具体方案**:

```
┌─────────────────────────────────────────────────────────┐
│                    创作工作台                             │
├─────────┬───────────────────────────────┬───────────────┤
│         │                               │               │
│ 项目    │        画布编辑区              │   AI助手面板   │
│ 导航    │                               │               │
│         │  ┌─────┐  ┌─────┐  ┌─────┐  │  ┌─────────┐  │
│ ├剧本   │  │角色  │→│分镜  │→│分镜  │  │  │AI编剧   │  │
│ ├角色   │  │节点  │  │节点1 │  │节点2 │  │  │AI分镜   │  │
│ ├场景   │  └─────┘  └─────┘  └─────┘  │  │AI配音   │  │
│ ├道具   │                               │  │AI优化   │  │
│ ├分镜   │  ┌─────┐  ┌─────┐           │  └─────────┘  │
│ ├音频   │  │场景  │  │道具  │           │               │
│ └导出   │  │节点  │  │节点  │           │  ┌─────────┐  │
│         │  └─────┘  └─────┘           │  │生成队列  │  │
│         │                               │  │进度监控  │  │
│         │  [时间轴 / 预览区]             │  └─────────┘  │
└─────────┴───────────────────────────────┴───────────────┘
```

**技术要点**:
- 基于现有 `DramaCanvas.vue` 扩展，整合剧本/角色/场景/分镜/音频管理
- 左侧增加项目导航树，右侧增加AI助手面板
- 底部增加时间轴预览区，支持拖拽排序
- 所有AI操作通过右侧面板触发，结果直接注入画布

**优先级**: P0

### 4.2 无限画布体验

**现状**: 基于 Vue Flow 实现节点式画布，支持节点拖拽、视口持久化（x/y/zoom）、水平对齐、集数筛选、暗色/浅色主题切换。但画布功能仍停留在"二维网格摆放"层面，缺乏高端创作平台应有的无限画布体验。

**改进目标**: 打造真正的无限画布——创作者可自由缩放、无限平移、分区组织、分支叙事，在一张画布上承载整部漫剧的完整创作脉络。

**具体方案**:

#### 4.2.1 多层级缩放与渐进式渲染

```
缩放级别          显示内容                    交互能力
─────────────────────────────────────────────────────────
10% (鸟瞰)    故事弧线 / 集数概览            拖拽集数区块
25% (概览)    分镜缩略图流 + 角色场景分组     框选 / 批量操作
50% (编辑)    分镜卡片 + 节点详情             拖拽 / 编辑 / 连线
100% (精编)   分镜大图 + 帧提示词 + 台词      逐帧编辑
200% (微调)   单帧画面 + 像素级参数           参数精调
```

**技术要点**:
- 基于 Vue Flow 的 zoom 配置扩展，不同 zoom 级别渲染不同节点组件
- 节点组件支持 `compact` / `normal` / `detailed` 三种视图模式
- 视口外的节点使用虚拟化（不渲染DOM），保证千级节点流畅
- 缩放过渡动画平滑（CSS transition + requestAnimationFrame）

#### 4.2.2 小地图导航器

**功能**: 画布右下角常驻小地图，显示全局节点分布和当前视口位置。

```
┌─────────────────────────────┐
│         画布编辑区            │
│                              │
│   节点  节点  节点           │
│     ╲   │   ╱                │
│      节点─节点               │
│                              │
│                    ┌──────┐ │
│                    │□□□  │ │  ← 小地图
│                    │ □   │ │     (当前视口框)
│                    └──────┘ │
└─────────────────────────────┘
```

**技术要点**:
- 使用 Vue Flow 内置 `<MiniMap>` 组件（需启用）
- 小地图支持点击跳转和拖拽视口
- 不同节点类型用不同颜色标识
- 支持小地图折叠/展开

#### 4.2.3 画布分区与智能布局

**功能**: 画布支持分区组织，不同类型内容放在不同区域，自动保持整洁。

```
┌──────────────────────────────────────────────┐
│                    画 布                      │
├──────────┬───────────────────┬───────────────┤
│          │                   │               │
│  角色区   │    分镜主流程区    │    场景区     │
│          │                   │               │
│  ┌────┐  │  ┌───┐ ┌───┐ ┌───┐│  ┌────┐ ┌────┐│
│  │角色1│  │  │镜1│→│镜2│→│镜3││  │场景1│ │场景2││
│  └────┘  │  └───┘ └───┘ └───┘│  └────┘ └────┘│
│  ┌────┐  │         │         │               │
│  │角色2│  │       ┌───┐       │  ┌────┐      │
│  └────┘  │       │镜4│       │  │场景3│      │
│          │       └───┘       │  └────┘      │
├──────────┤                   ├───────────────┤
│  道具区   │                   │   参考素材区   │
│  ┌────┐  │                   │  ┌────┐ ┌───┐ │
│  │道具1│  │                   │  │参考1│ │参2│ │
│  └────┘  │                   │  └────┘ └───┘ │
└──────────┴───────────────────┴───────────────┘
```

**技术要点**:
- 画布增加"分区"概念，分区可折叠/展开/拖拽
- 新建节点时自动放入对应分区
- 分区间用半透明背景色区分
- 支持"一键整理布局"（按类型自动分区排列）
- 扩展现有 `CanvasFlowAligner.vue` 支持分区对齐

#### 4.2.4 分支叙事支持

**功能**: 支持在画布上创建分支剧情，可视化展示多条故事线。

```
                    ┌─────────┐
                    │ 第3集    │
                    │ 主线剧情 │
                    └────┬────┘
                    ╱         ╲
          ┌─────────┐         ┌─────────┐
          │ 分支A    │         │ 分支B    │
          │ 结局：HE │         │ 结局：BE │
          └─────────┘         └─────────┘
```

**技术要点**:
- 分镜节点支持"分支标记"属性
- 画布连线支持条件标签（选择A→分支A，选择B→分支B）
- 导出时可选择导出特定分支或全部分支
- 分支节点用特殊颜色/形状区分

#### 4.2.5 画布搜索与定位

**功能**: 在大画布中快速搜索和定位特定节点。

**具体方案**:
- 顶部增加搜索框，支持按节点名称/内容/ID搜索
- 搜索结果列表展示，点击自动平移+缩放到目标节点
- 支持按类型筛选（只看角色/只看分镜/只看场景）
- 支持按状态筛选（未生成/生成中/已完成的分镜）
- 快捷键 `Cmd+F` / `Ctrl+F` 唤起搜索

#### 4.2.6 画布书签与视图快照

**功能**: 保存常用画布视图，一键跳转。

**具体方案**:
- 画布顶部增加书签栏，可保存当前视口为书签
- 书签记录视口位置（x/y/zoom）和筛选状态
- 支持书签命名和分组（如"第一集""角色设计""修改区"）
- 书签数据持久化到项目 metadata

#### 4.2.7 画布标注与批注

**功能**: 在画布上添加自由标注，辅助创作思考。

**具体方案**:
- 画布工具栏增加"标注"工具
- 支持文字标注、箭头标注、矩形框选标注
- 标注不参与生成流程，仅辅助创作
- 标注颜色可自定义，支持设置提醒
- 与协作功能联动：标注可@团队成员

#### 4.2.8 性能保障

**技术要点**:
- 视口外节点虚拟化（仅渲染可视区域 + 缓冲区节点）
- 节点图片懒加载（缩略图优先，悬停/点击加载高清图）
- 画布操作使用 `requestAnimationFrame` 节流
- 大量节点时自动降级（隐藏连线动画、简化节点样式）
- Vue Flow 配置 `nodeExtent` 限制重绘范围

#### 4.2.9 3D导演台模式

**功能**: 在无限画布基础上增加3D空间视图，让创作者以"导演"视角在三维空间中编排故事节奏、场景层次和镜头运动，突破2D平面的表达局限。

**核心场景**:

```
┌─────────────────────────────────────────────────────────┐
│                   3D 导演台                              │
│                                                          │
│    Z轴(深度)                                             │
│    ↑                                                     │
│    │  ┌────────┐              ┌────────┐               │
│    │  │ 背景层  │ ← 远景场景    │ 背景2  │               │
│    │  └────────┘              └────────┘               │
│    │       ┌──────────┐                    ┌────────┐  │
│    │       │ 中景层    │ ← 角色站位/道具    │ 中景2  │  │
│    │       └──────────┘                    └────────┘  │
│    │            ┌─────────────┐                         │
│    │            │  前景层      │ ← 特写/前景遮挡         │
│    │            └─────────────┘                         │
│    │                                                     │
│    └──────────────────────────────────────────────→ X轴(时间线)
│    第1镜    第2镜    第3镜    第4镜    第5镜  ...       │
│                                                          │
│    📷 虚拟摄像机：可推/拉/摇/移/跟，实时预览镜头效果      │
└─────────────────────────────────────────────────────────┘
```

**具体功能**:

| 功能 | 说明 | 价值 |
|------|------|------|
| **三维空间编排** | 分镜节点在X(时间)/Y(层级)/Z(深度)三轴上自由排布 | 直观呈现故事的空间结构 |
| **层级分离** | 背景/中景/前景分层显示，每层独立编辑 | 模拟真实影视拍摄的空间层次 |
| **虚拟摄像机** | 可放置虚拟摄像机，调整焦距/角度/高度 | 实时预览不同镜头语言效果 |
| **镜头运动模拟** | 推/拉/摇/移/跟/升/降等运镜方式可视化 | 导演视角规划镜头节奏 |
| **场景深度预览** | 3D空间中预览场景图片的透视和遮挡关系 | 提前发现构图问题 |
| **角色站位编排** | 角色以3D模型/卡片形式放置在场景空间中 | 规划角色走位和互动关系 |
| **时间轴3D化** | 分镜沿X轴排列，形成3D故事时间线 | 直观把握全片节奏和结构 |
| **2D/3D切换** | 一键在2D画布和3D导演台之间切换 | 兼顾精细编辑和全局编排 |

**交互设计**:

```
3D导演台操作方式:
  - 鼠标拖拽空白处: 旋转视角
  - 滚轮: 缩放
  - 右键拖拽: 平移
  - 点击节点: 选中并显示详情
  - 拖拽节点: 在3D空间中移动(支持X/Y/Z三轴)
  - 双击节点: 进入2D精编模式
  - 快捷键 1/2/3: 切换 正视图/侧视图/俯视图
  - 快捷键 0: 切换 自由视角
```

**技术要点**:

- **3D引擎选型**: 使用 Three.js（生态成熟，与 Vue 集成方案多）
- **节点3D化**: 2D节点卡片映射为3D平面（PlaneGeometry + 纹理贴图）
- **层级管理**: 背景/中景/前景分别放置在不同Z深度平面
- **摄像机系统**: PerspectiveCamera + OrbitControls，支持预设机位
- **性能优化**: 视口外节点不渲染3D网格，使用LOD（Level of Detail）降级
- **数据同步**: 3D布局数据（position3D: {x,y,z}）持久化到 canvas_layout
- **与2D画布联动**: 3D模式修改的节点位置同步回2D画布，反之亦然

**数据结构扩展**:

```javascript
// 节点3D布局数据（扩展 canvas_layout）
{
  version: 2,
  viewport: { x: 0, y: 0, zoom: 0.75 },
  view_mode: "2d" | "3d",        // 当前视图模式
  camera_3d: {                    // 3D摄像机参数
    position: { x: 0, y: 5, z: 10 },
    target: { x: 0, y: 0, z: 0 },
    fov: 50,
  },
  nodes: {
    "node_001": {
      x: 100, y: 200,             // 2D坐标
      z: 0,                       // 3D深度(0=前景, 100=中景, 200=背景)
      layer: "foreground",        // 所属层级
      camera_preset: "close_up",  // 镜头预设
    }
  }
}
```

**优先级**: P2 — 3D导演台是高端差异化能力，2D画布完善后作为进阶体验推出

```
智能路由决策示例（模型名称仅为示意，实际以配置为准）:
  任务: 生成角色头像 (简单任务)
```

## 十四、总结

当前项目已具备扎实的架构基础和丰富的功能模块，核心改进方向是：

1. **智能化** — 从"工具"升级为"AI创作伙伴"，让AI深度参与编剧、分镜、配音、剪辑全流程
2. **一致性** — 解决角色/风格跨分镜一致性问题，这是漫剧质量的根本保障
3. **一体化** — 打散分散的功能页面，构建一站式创作工作台
4. **无限画布** — 多层级缩放、分区组织、分支叙事、小地图导航，一张画布承载完整创作脉络
5. **协作化** — 引入团队协作和版本管理，支持多人创作
6. **运营智能化** — 后台从"管理工具"升级为"智能运营中枢"，实现AI模型智能路由、内容自动审核、用户生命周期管理、实时成本核算
7. **商业化** — 建立会员体系和模板市场，实现可持续盈利

按本规划实施后，LocalMiniDrama 将从"功能丰富的创作工具"升级为"高端智能漫剧创作平台"，在漫剧创作赛道建立技术壁垒和产品优势。
