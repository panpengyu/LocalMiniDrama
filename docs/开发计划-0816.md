## 二、Sprint 17：商业化闭环（财务 + 支付 + 会员）

**目标**：管理端能运营会员充值链路；支付宝真实可用；会员权益承诺与实现一致。

### T17-01 充值套餐管理
- 后端：`recharge_plans` 表（名称/价格/额度/等级/状态/排序）+ `routes/finance.js` 增 CRUD 接口 + `membership` 下单时读取套餐。
- 前端：`front-admin/src/views/finance/RechargePlans.vue` 实现列表/新增/编辑/上下架。
- 验收：套餐增删改查可用；用户端会员中心展示并可用套餐下单。

### T17-02 优惠券管理
- 后端：`coupons` 表（券码/面额/门槛/有效期/适用范围/库存）+ 兑换与核销接口 + 订单抵扣逻辑。
- 前端：`front-admin/src/views/finance/Coupons.vue`（列表/发放/失效）；用户端会员中心增加"兑换码"入口。
- 验收：创建优惠券→兑换→下单抵扣→核销全链路可跑通。

### T17-03 支付配置
- 后端：`routes/finance.js` 增加支付配置读写接口（微信商户号/证书/支付宝 APPID/私钥），配置加密存储。
- 前端：`front-admin/src/views/finance/PaymentConfig.vue`（表单+连通性测试按钮）。
- 验收：配置保存后可调用"测试支付"回调返回成功。

### T17-04 支付订单
- 后端：`payment_orders` 查询接口（筛选：状态/渠道/时间/用户）、关单、退款（微信退款接口）。
- 前端：`front-admin/src/views/finance/PaymentOrders.vue`（列表/详情/手动关单/退款）。
- 验收：微信支付产生的订单可在管理端查询与操作。

### T17-05 全局计费
- 后端：按等级/资源类型的计费规则配置接口 + 全局消费统计聚合。
- 前端：`front-admin/src/views/finance/GlobalBilling.vue`（计费规则编辑 + 全局收入/成本看板）。
- 验收：修改计费规则后新任务按新规则计费。

### T17-06 支付宝支付接入
- 后端：引入 `alipay-sdk`，实现统一下单（当面付/电脑网站支付）、回调验签（替换占位 `verifyAlipaySignature` 恒 false）、退款。
- 前端：会员中心支付方式增加"支付宝"；支付配置页增加支付宝参数。
- 验收：支付宝沙箱环境完成"下单→支付→回调→开通会员"闭环。

### T17-07 会员权益承诺修正
- 后端/前端：专业版权益文案中"LoRA 训练"改为"角色一致性增强（IP-Adapter）"或标注"敬请期待"。
- 验收：所有权益文案与真实能力一致，无虚假承诺。

## 三、Sprint 18：运营增强（看板 + 埋点 + 数据）

**目标**：运营有数据、看板可订阅、报表可导出。

### T18-01 事件埋点服务
- 后端：`tracking_events` 表（user_id/event/attrs/ts）+ `trackingService.js`（collect/批量落库/定时聚合）+ 防刷限流。
- 前端：`front-user/src/utils/tracking.js` 埋点 SDK（自动上报页面浏览、关键操作：进入画布/生成成功/导出/付费转化），`front-admin` 同埋。
- 验收：埋点事件入库；`tracking_events` 聚合接口返回漏斗/留存数据。

### T18-02 留存与转化分析接入
- 后端：`analyticsService.js` 增加留存分析（D1/D7/D30）、转化漏斗（注册→创作→生成→付费）、路径分析接口。
- 前端：`DataAnalytics.vue` 增加对应图表页签。
- 验收：埋点数据驱动出留存/漏斗图表。

### T18-03 报表订阅
- 后端：`report_subscription` 表（类型/周期/接收渠道/收件人）+ `reportJobService.js`（node-cron 按日/周/月生成）+ `notifyService.js`（邮件 SMTP / 钉钉群机器人 webhook 适配）。
- 前端：`front-admin/src/views/operation/ReportSubscribe.vue`（新增/编辑订阅、查看发送历史）。
- 验收：配置订阅后到点自动生成并推送；推送失败有日志与重试。

### T18-04 自定义仪表盘
- 后端：`dashboard_layout` 表（admin_id/布局 JSON）+ CRUD 接口。
- 前端：`Dashboard.vue` 支持组件拖拽（vuedraggable）、组件池（实时指标/异常洞察/漏斗/模型成本/财务），按管理员持久化。
- 验收：两个管理员可各自配置不同布局并互不影响。

### T18-05 数据导出 / 自定义报表
- 后端：统计接口支持 `?export=csv/xlsx`；新增 `report_templates` 自定义报表（选定指标+维度生成）。
- 前端：`DataAnalytics.vue` 各图表加"导出"按钮；自定义报表编辑器。
- 验收：运营数据可一键导出为 CSV/XLSX。

## 四、Sprint 19：模型中枢与安全加固

**目标**：AI 成本可控、模型可选可测；账号安全达到企业级。

### T19-01 模型 A/B 测试
- 后端：`modelRoutingService` 增加 `abTest` 配置（任务类型/模型组/流量比例/并行调用），结果写入 `ai_model_call_logs`（ab_group 字段）；生成对比报告（成功率/耗时/质量/成本）。
- 前端：`front-admin` 模型网关页增加 A/B 测试管理（创建/启停/查看报告）。
- 验收：A/B 期间同一任务按比例路由到不同模型，报告可对比并支持"一键设为默认路由"。

### T19-02 模型用量配额管理
- 后端：`model_usage_quota` 表（主体类型 user/team/enterprise + model + 周期 + 限额）+ 路由前配额校验 + 超限告警。
- 前端：模型网关页增加配额管理（按用户/团队/企业设置）。
- 验收：超配后调用被拦截并返回明确错误码与升级提示。

### T19-03 安全策略
- 后端：`security_policy` 配置表（密码复杂度/有效期/尝试锁定次数/锁定时长/登录 IP 白名单/2FA 开关）+ 登录中间件实现（TOTP 校验可引入 `otplib`）。
- 前端：`front-admin/src/views/system/SecurityPolicy.vue` 配置页；用户端个人中心增加"绑定身份验证器"。
- 验收：配置开启后，弱密码注册被拒、连续失败锁定、白名单外 IP 登录被拒、2FA 验证生效。

### T19-04 会话管理
- 后端：`user_sessions` 表（session_id/user_id/登录IP/UA/过期时间/状态），JWT 校验时核对会话状态；强制下线接口。
- 前端：`front-admin/src/views/system/OnlineSessions.vue`（在线会话列表/强制下线）；`security.js` 增加对应接口。
- 验收：强制下线后该用户请求立即失效。

## 五、Sprint 20：创作体验增强

**目标**：补齐需求文档中的画布/评论/剪辑交互能力。

### T20-01 分支叙事
- 后端：`episodes`（或 storyboards）表增加 `branch_id/branch_type` 字段；剧本导出接口支持按分支切分；`branch` 相关迁移 SQL。
- 前端：画布节点增加"开启分支"操作与分支标记样式；支持条件连线（拖动节点连线并选择条件）；分支模式切换；导出时按分支生成剧本。
- 验收：创建分支→分支内新增分镜→切换分支→按分支导出剧本，全链路可用。

### T20-02 语音评论
- 后端：`comments` 表增加 `type/audio_url/audio_duration`；上传接口复用 `/static` 存储。
- 前端：评论面板增加录音按钮（MediaRecorder，15-60s 上限）、播放器、时长展示。
- 验收：录音→上传→其他协作者可播放。

### T20-03 智能剪辑前端面板扩展
- 前端：`SmartEditTimeline.vue` 增加字幕（文本/样式/多语言）、水印（图片/位置/透明度）、调色（滤镜/亮度/对比度）设置面板，透传后端参数。
- 后端：核对接入参数（`videoService` 已具备能力，补齐字段映射）。
- 验收：设置字幕/水印/调色后生成的成片包含对应效果。

### T20-04 音效智能匹配
- 后端：`sfxService.js`（音效素材库 + 场景标签匹配 + 强度控制）+ 成片合成阶段叠加音效轨。
- 前端：配音同步界面增加"自动添加音效"开关与音效预览。
- 验收：选择"动作场景"后成片在对应位置叠加音效。

## 六、Sprint 21：运维与通用管理页

**目标**：系统可运维、内容合规、占位页清零。

### T21-01 版权检测
- 后端：素材上传时计算 pHash → `asset_fingerprint` 表；与公共素材库指纹比对，超阈值标记风险；审核工作台展示版权风险标识。
- 验收：上传近似公共素材的图片被标记为"疑似侵权"。

### T21-02 运维自动化
- 后端/脚本：`deploy/opsScripts/`（backup.sh / restore.sh / rollback.sh）+ 定时备份任务（可配 cron）+ `routes/ops.js` 触发接口。
- 前端：`front-admin/src/views/system/OpsCenter.vue`（备份列表/一键备份/恢复/回滚）。
- 验收：执行备份生成文件；执行恢复后数据完整；回滚可还原上一发布版本（需配合 Git tag + PM2 重启）。

### T21-03 自动扩缩容（轻量）
- 后端：监控模块输出扩容建议（CPU>70% 持续 5min / 队列积压>N）；`deploy/pm2.ecosystem.json` 支持 max_restarts/instances 调整；接入 PM2 cluster 配置说明。
- 验收：监控页展示扩缩容建议指标。

### T21-04 通用管理页补齐（20 个占位页）
> 按依赖关系分三批，每批含 后端接口 + 前端页面：
> - **批A（用户/内容运营）**：`Users.vue`（用户管理列表+禁用/重置）、`Teams.vue`（团队列表/成员）、`Works.vue`（作品列表/下架）、`PublicAssets.vue`（公共素材库管理）、`ActorLibrary.vue`（演员库，可挂接角色一致性）。
> - **批B（站点配置）**：`SiteBrand.vue`（站点名称/LOGO/ICP）、`Notices.vue`（公告管理）、`Agreements.vue`（用户协议）、`TosConfig.vue`（服务条款）、`Changelog.vue`（更新日志，对接前端更新提示）、`SmsConfig.vue`（短信签名/模板）、`Channels.vue`（渠道管理，渠道码追踪注册来源）。
> - **批C（系统管理）**：`Admins.vue`、`Roles.vue`（RBAC 角色-菜单-权限）、`Menus.vue`、`Dict.vue`、`Params.vue`、`LogSearch.vue`（操作日志检索）、`Troubleshoot.vue`（自检工具：环境信息/缓存状态/队列状态）。
- 验收：25 个占位页全部替换为真实页面；路由中无"功能开发中"提示。

### T21-05 任务队列 Bull/Redis 化（可选优化）
- 后端：`config.yaml` 配置 Redis 后启用 Bull；`queueService` 增加 Bull 适配层（保留内存降级）；断点续传/重试迁移。
- 验收：Redis 开启时任务跨进程可见、重启不丢失。
